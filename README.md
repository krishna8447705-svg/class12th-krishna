# AI Chatbot

A simple terminal chatbot using the OpenAI API.

## Setup

1. Install Python 3.10 or newer.
2. Install the dependency:

	```powershell
	py -m pip install -r requirements.txt
	```

3. Set your API key in PowerShell for the current terminal:

	```powershell
	$env:OPENAI_API_KEY = "your-api-key-here"
	```

4. Start the chatbot:

	```powershell
	py chatbot.py
	```

Never commit an API key to the repository.
